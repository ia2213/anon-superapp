# AnonSuperApp Flutter App

Mobile application for the AnonSuperApp platform.

## Getting Started

```bash
cd flutter_app
flutter pub get
flutter run
```

## Features

- 🔍 Anonymous Web Search (SearXNG + Tor)
- 💳 Crypto Wallet & Low-KYC Prepaid Cards
- 💬 P2P Encrypted Messaging
- 📁 Secure File Transfer
